# Recordings

The clips the cases ask for, one phrase per file, named as the case's
`audio` field names it. A clip that is not here runs as its transcript,
so record what you like; the ones below give the bench its speech signal
(names, numbers, German, a spoken address, the short turns of a flow).

How to record: Voice Memos on the iPhone (or the Mac), one phrase per
memo, a quiet second before and after, said the way you would to the
app. Share → Save to Files, rename to the file name below (Voice Memos
exports `.m4a`; any file AVAudioFile reads works), drop it here. Say the
words as the transcript has them, so the word error rate means
something; the punctuation is not spoken.
